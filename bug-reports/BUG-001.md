# BUG-001: Sorting products resets cart state

**Severity:** Medium
**Priority:** High
**Status:** Open
**Environment:** Chrome, Windows 11 (SauceDemo)

**Description:**
When a user adds an item to the cart and then changes the product sorting order, the UI incorrectly updates the cart state. Items that were not added by the user suddenly show as "Remove".

**Steps to Reproduce:**
1. Log in as standard_user.
2. Click "Add to cart" for the Sauce Labs Backpack.
3. Observe the cart badge count is 1.
4. Change sort to "Name (Z to A)".
5. Observe the cart badge count.

**Expected Result:**
The cart badge should stay at 1.

**Actual Result:**
The cart badge changes to 2. The Sauce Labs Onesie suddenly shows a "Remove" button.
